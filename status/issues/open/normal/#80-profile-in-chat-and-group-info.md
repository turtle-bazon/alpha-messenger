# #80 — Профиль пользователя в чатах + Информация о группе

## 1. Профиль пользователя в личном чате

Клик на аватар автора сообщения в **личном чате** → открывает профиль собеседника.

## 2. Информация о группе

Клик по заголовку группы → `GroupInfoDialog` (вместо прямого открытия MembersDialog):

- Название группы (owner может редактировать)
- Описание группы (owner может редактировать)
- Кнопка «Участники» → открывает `MembersDialog`

### Сервер

- Новое поле `description` в таблице `chats` (миграция)
- `PATCH /api/chats/:chatId` — обновление title/description (только владелец)
- Расширить `GET /chats/:chatId` — возвращать `description`

### Клиент

- `GroupInfoDialog` — новая модалка
- Изменить клик по заголовку группы → открывать `GroupInfoDialog`
- `MembersDialog` открывается из `GroupInfoDialog` по кнопке
