# #80 — Профиль пользователя в чатах + Информация о группе

## 1. Профиль пользователя в чатах

Открытие профиля пользователя по клику на аватар/имя **внутри чата** (не только в списке чатов):

- Клик на аватар автора сообщения в **личном чате** (не только в группе) — открывает профиль собеседника
- Клик на аватар в **шапке conversation** для direct-чата уже работает (#22)

## 2. Информация о группе для всех участников

Сейчас окно участников (MembersDialog) открывается только кликом по заголовку группы. Нужно:

- **Для всех участников** (включая не-владельцев): клик по заголовку группы открывает **информацию о группе** (название, описание)
- **Для владельца**: возможность редактировать название и описание группы
- **Для не-владельцев**: только просмотр (без списка участников и без возможности добавления/удаления)
- Список участников по-прежнему доступен, но как отдельное действие (кнопка «Участники» в информации о группе)

### Схема поведения

```
Клик по заголовку группы:
├── Владелец → GroupInfoDialog (название, описание, редактирование)
│   └── Кнопка «Участники» → MembersDialog
└── Участник → GroupInfoDialog (название, описание, просмотр)
    └── Кнопка «Участники» → MembersDialog (только просмотр)
```

### Сервер

- `PATCH /api/chats/:chatId` — обновление `title` и/или нового поля `description` (только для владельца)
- Расширить `GET /chats/:chatId` — возвращать `description`

### Клиент

- `GroupInfoDialog` — новая модалка с информацией о группе
- Изменить поведение `conv-headline` для групп: открывать `GroupInfoDialog` вместо `MembersDialog`
