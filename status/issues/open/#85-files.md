# #85 — Файлы и документы

Отправка файлов любого типа (не только картинок), как в Telegram: карточка
с именем/размером в пузыре, скачивание по клику.

## Реализация (только клиент)
- Конверт: `FileAttachment { kind:'file', blobId, name, mime, size }`
  (encode k:'file': blob/name/mime/size).
- Композер: существующий input 📎 принимает любые файлы; image/* идёт в
  редактор как раньше, остальное — сразу как файловое вложение.
- Пузырь: карточка (иконка, имя, размер), клик — скачать (fetch блоба с
  токеном → objectURL → a[download]).
- Превью списка: «📎 {имя}».
- Отправка через существующую очередь (media-слот уже обобщён? нет —
  расширить enqueueSend/pump на file-вложения аналогично audio/video).
