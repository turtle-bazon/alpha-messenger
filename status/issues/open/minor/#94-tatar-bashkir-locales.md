# #94 — Татарский и башкирский языки

Focus-тикет: board id 94, «New languages».

## Реализация
- `src/i18n/locales/tt.json` и `ba.json` — полные переводы (285 ключей,
  паритет с en по ключам и плейсхолдерам проверен скриптом).
- Зарегистрированы в `i18n/index.ts`: LANGS («Татарча», «Башҡортса»,
  после ru) + INTL_LOCALES (tt-RU, ba-RU). RTL не нужен (кириллица).
- Множественные числа: CLDR для tt/ba — только категории one|other;
  suffixed-ключи membersCount/subscribers заполнены во всех формах
  (few/many оставлены = other, как в остальных локалях).
- Автоопределение языка браузера подхватит tt/ba автоматически.
