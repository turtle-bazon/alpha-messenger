# #58 — Мультиязычность (i18n)

Добавить поддержку нескольких языков в интерфейсе клиента.

## Статус реализации (2026-08-21)
Сделано:
- Инфраструктура: i18next + react-i18next, `src/i18n/` с локалями
  `locales/{ru,en}.json`. Локали грузятся лениво (динамический import,
  отдельный чанк на язык — видно в сборке vite).
- Автоопределение языка браузера при первом запуске (`navigator.languages`,
  ru* -> ru, иначе en), выбор хранится в localStorage (`alpha.lang`).
- Переключатель языка в настройках (settings-language), имя языка — на самом
  языке (Русский/English).
- Мигрированы все UI-строки (~350 в ~35 файлах): auth, setup, home,
  chatlist, conversation, все диалоги, звонки, медиа, редактор изображения,
  стикеры, уведомления, устройства. Плюралы через суффиксы i18next
  (_one/_few/_many/_other) для «участников» и «подписчиков». Дата/время
  следуют языку (intlLocale()).
- Не-React модули (time.ts, content.ts, chatTitle.ts, notifications.ts,
  android-setup.ts) используют инстанс i18next напрямую; в WS-колбэках —
  тоже (t из хука там протухает).
- E2E: e2e/i18n.spec.ts (автодетект по локали — прогнан, переключение в
  настройках — требует БД). Все контексты playwright закреплены за ru-RU
  (config + newContext), чтобы существующие сценарии с русскими ассертами
  не зависели от автодетекта.

Осталось:
- RTL (см. ниже) — отложено: без RTL-локали (ar/he/...) нечем проверять.
  Понадобит logical properties по всему index.css.
- Ключевые слова эмодзи в EmojiPicker остаются русскими (поисковый
  датасет, ~300 строк) — локализовать при добавлении третьей локали.
- Прогон полного e2e-регресса на стеке run/dev.

## Текущее состояние
Все строки интерфейса захардкожены на русском языке. Нет системы локализации.

## Поведение
- Переключение языка в настройках
- Автоопределение языка браузера при первом запуске
- Сохранение выбора в localStorage
- Загрузка строк по требованию (не все языки сразу)

## RTL (right-to-left)
Для арабского, иврита, фарси и т.д.需要:
- Направление текста `dir="rtl"` на корневом элементе
- Зеркальный CSS (flip) для layout: sidebar справа, стрелки влево, выравнивание
- `flex-direction: row-reverse` / `margin-left` ↔ `margin-right` через CSS-переменные или logical properties
- Чат-список и сообщения: отправитель справа, получатель слева (как в Telegram)
- Текстовые поля: выравнивание по правому краю
- Иконки с направлением (стрелки, навигация) — зеркалить
- Не зеркалить иконки без направления (сердце, звезда и т.д.)

## Реализация
- Библиотека: i18next + react-i18next (или аналог)
- Структура: `src/i18n/locales/{ru,en}.json` (один namespace translation)
- Хук `useTranslation()` для доступа к строкам
- Постепенная миграция строк (не всё сразу)
