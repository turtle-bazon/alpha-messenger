# #89 — Ширина чата на телефоне: панель переписки обрезается

Focus-тикет: board id 75, «Chat width». Симптом: в Android-приложении в
некоторых чатах контент обрезается справа без горизонтального скролла
(в браузере тот же клиент — ок; десктопmasked изобилием ширины).

## Диагностика
Временный HUD (внутренние размеры viewport + список элементов за краем
экрана) показал на устройстве: inner=client=visual=360, scale=1.0 —
viewport нормальный; за правый край выходят сами контейнеры
`.conversation`, `.conv`, `.conv-header`.

## Причина
`.conversation` — flex-элемент строки `.home` — не имел `min-width:0`,
поэтому не сжимался ниже min-content своего содержимого: чат с «широким»
элементом распирал всю панель, а `overflow:hidden` у `.app-shell`
обрезал её без скролла. Затрагивал только чаты с раздувающим контентом.

## Решение
`min-width: 0` для `.conversation` (commit 92422d1). Подтверждено
пользователем на устройстве: чат помещается, ovr:- .

Попутно по тому же тикету (защитные фиксы, не причина):
- #87-боксы изображений без зависимости от CSS aspect-ratio (b6210b6);
- text-size-adjust:100% против font boosting (b2e7fc2);
- useWideViewPort/overview для загрузки кеша через loadDataWithBaseURL
  (5f2c252).
