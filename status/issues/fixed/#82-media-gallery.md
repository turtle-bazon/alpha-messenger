# #82 — Галерея медиа чата

Сетка всех фото/видео чата (как в Telegram: кнопка в шапке профиля чата).

## Сервер
- `GET /chats/:chatId/media?before=<messageId>&limit=60` — только участнику.
  Раскодирует ciphertext сообщений (base64 JSON, как в SSR channel-web),
  отбирает сообщения с вложениями kind:'image'|'video', отдаёт элементы:
  `{ messageId, ts, att }` (att целиком — thumb уже внутри). Пагинация по
  messageId назад, limit ≤ 100.

## Клиент
- Кнопка «галерея» в заголовке чата → диалог-сетка (`MediaGallery.tsx`).
- Плитки из inline-thumb (без запросов блобов); клик → MediaViewer (полный блоб).
- Ленивая подгрузка при скролле вниз (before = последний messageId).
- Видео-плитки — с бейджем длительности.
