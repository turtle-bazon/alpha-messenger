# #84 — Пересылка сообщений

Пересылка сообщения в другой чат (как в Telegram): пункт «Переслать…» в
контекстном меню, выбор чата, шапка «Переслано от X» в пузыре.

## Реализация (только клиент)
- Конверт содержимого: опциональное поле `fwd: { from }` в MessageContent
  (encode/decode в util/content.ts). Сервер не меняется — это часть ciphertext.
- Отправка: тот же контент + `fwd`, те же blobIds (блобы уже существуют,
  content-addressed — повторная загрузка не нужна).
- ForwardDialog на уровне HomeScreen (там живёт список чатов): поиск по названию,
  клик — переслать. Из Conversation — колбэк onForward(message).
- Рендер: строка «Переслано от {имя}» над текстом/вложениями.
