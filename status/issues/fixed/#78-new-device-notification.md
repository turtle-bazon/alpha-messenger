# #78 — Уведомление о входе с нового device ID

## Описание
При входе пользователя с нового device ID (новое устройство/браузер) — отправлять уведомление на все активные сессии пользователя.

## Реализация
- Сервер: `device.added` event эмитится при регистрации нового устройства (в `auth.ts`)
- Сервер: `auth.attempt` event эмитится при каждом входе
- Клиент: компонент `AccountNotifications` обрабатывает оба события и показывает уведомление
- Уведомление: "Новый вход в аккаунт с нового устройства" (если устройство новое) или "Новый вход в аккаунт"
- Показывается IP-адрес источника

## Статус
Готово — реализовано в `AccountNotifications.tsx`.
