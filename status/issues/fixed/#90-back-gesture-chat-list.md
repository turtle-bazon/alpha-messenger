# #90 — Системный Back в чате возвращает к списку (мобильные)

Focus-тикет: board id 92, «Chat back to chat list on mobile».
Жест «назад» от левого края в Android закрывал приложение вместо
возврата из чата к списку.

## Решение (двухслойное)
1. Веб (99df20a, cc9beb7): в одноколоночном режиме (≤600px) открытие
   чата кладёт запись в историю (pushState), popstate закрывает чат;
   кнопка «Назад» и удаление чата съедают свою запись. Работает в
   мобильных браузерах; десктоп не затронут.
2. Нативно (7373bef): ядро Capacitor 6 вообще не обрабатывает Back
   (@capacitor/app не установлен) — жест завершал Activity, до истории
   WebView дело не доходило. OnBackPressedDispatcher в MainActivity:
   webView.goBack() при наличии истории, иначе дефолтное поведение.

Требуется пересборка APK для п.2.
