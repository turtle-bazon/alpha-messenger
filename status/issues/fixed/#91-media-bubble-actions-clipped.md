# #91 — Медиа-пузырь: обрезаны действия и имя отправителя

Focus-тикет: board id 93. На сообщениях с картинкой оверлей действий
(реакция/ответ) обрезался, а имя отправителя прижималось к скруглённым
углам; на текстовых сообщениях всё было нормально.

## Причина
`.bubble--media` имел `overflow:hidden` — он резал `.bubble-actions`
(позиционированы на top:-12px, вне пузыря). Плюс `padding:0` лишал
отступов имя отправителя/подпись/время внутри медиа-пузыря.

## Решение (803f995)
Убран overflow:hidden (радиусы углов картинок обрабатывают явные
правила first/last/only-child для img); текстовым блокам внутри
медиа-пузыря задан явный паддинг (sender/caption/text/footer).
Проверено локальным HTML-харнесом: медиа-пузырь рендерится как
текстовый. Web-only, без пересборки APK.
