# Дорожная карта следующих улучшений

Анализ относительно Telegram (Desktop/мобильный), WhatsApp, Signal — по состоянию
alpha-messenger на август 2026. Основа: уже есть direct/группы/каналы, медиа
(фото/стикеры/GIF/голосовые/видео-сообщения), звонки 1-на-1, пуш, presence,
drafts, реакции, ответы, unfurl, кеш сообщений, десктоп и Android клиенты.

## Чего не хватает относительно эталонов

## Приоритизированный план

### Фаза 0 — стабилизация (немедленно)
1. Прогнать полный регресс против поднятого стека: серверные тесты + все e2e,
   включая новые `voice-video.spec.ts` и `calls.spec.ts` (написаны, не гонялись).
2. Закрыть накопленные UX-баги: #46 (localStorage при логауте), #48 (иконка
   окна), #72 (клавиатура на мобилке), #49 (emacs-комбо).

### Фаза 1 — контент (самый большой разрыв с эталонами)
3. **Файлы и документы** (#31): kind:'file' вложение, карточка имя/размер,
   скачивание; range-запросы к блобам для видео; лимиты размеров.
4. **Галерея медиа чата**: сетка всех фото/видео из истории, ленивая подгрузка,
   переход к сообщению.
5. **Поиск сообщений**: клиентский (IndexedDB-кеш уже есть) в чате + глобальный;
   серверный поиск по каналам (SSR-страницы тоже).
6. **Пересылка + мультивыбор**: forward без цитирования истории, батч-удаление.
7. **Закреплённые сообщения**: закрепить/открепить, плашка сверху чата.

### Фаза 2 — управление чатами
8. **Закрепление и архив чатов** (клиентские флаги + сортировка списка).
9. **Per-chat уведомления** (#79): mute/приоритет, хранение на сервере.
10. **Инвайт-ссылки в группы**: токен → join по ссылке (как каналы, но приватно).
11. **Права админов**: роли admin/promote, ограничения постинга.

### Фаза 3 — звонки v2
12. **История звонков**: системные сообщения «Пропущенный звонок…» через outbox.
13. **Демонстрация экрана**: getDisplayMedia как замена камеры в звонке.
14. **TURN** (coturn в run/) для симметричных NAT.

### Фаза 4 — платформа
15. **i18n** (#58): вынести UI-строки, ru/en локали (международная разработка).
16. **Автообновление** (#43): манифест уже генерится — допилить установку.
17. **Анимированные стикеры** (webm/Lottie) + недавние стикеры (остаток #63).
18. **Цветовой badge** (#42) + libnotify (#75) — десктопная полировка.

### Фаза 5 — безопасность (стратегически)
19. **Настоящее шифрование**: интерфейс encode/decode уже готов под ключи
    (`key` у вложений зарезервирован). Этап 1 — транспортное шифрование контента
    серверным ключом; этап 2 — секретные чаты с E2EE (X3DH+Double Ratchet или
    MLS для групп). Самый дорогой пункт, но ключевой для позиционирования.

## Не планируется (осознанно)
- Истории/stories, боты, платежи, суперреакции — не ядро мессенджера.
- Папки чатов — после архива, если будет спрос.
